# 🌐 Web_v1.0.0

Proyecto web desarrollado con Next.js, TypeScript y Tailwind CSS, desplegado en Vercel.

## 🚀 Demo

🔗 https://apf-web-nu.vercel.app/

## 📋 Características

- Diseño responsive.
- Desarrollo con Next.js.
- Tipado estático mediante TypeScript.
- Estilos con Tailwind CSS.
- Optimización para producción mediante Vercel.

## 🛠️ Tecnologías utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/aleperezfuente/APF-Web.git
```

Accede al directorio:

```bash
cd APF-Web
```

Instala las dependencias:

```bash
npm install
```

## ▶️ Ejecutar en desarrollo

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:3000
```

## 🏗️ Compilar para producción

```bash
npm run build
```

## 🚀 Ejecutar la versión de producción

```bash
npm start
```

## 📁 Estructura del proyecto

```text
web/
├── app/
│   ├── components/      # Componentes reutilizables de la interfaz
│   ├── lib/             # Utilidades, funciones y lógica compartida
│   ├── globals.css      # Estilos globales
│   ├── layout.tsx       # Layout principal de la aplicación
│   └── page.tsx         # Página principal
├── .gitignore           # Archivos ignorados por Git
├── next-env.d.ts        # Tipos de Next.js
├── package-lock.json    # Versiones exactas de dependencias
├── package.json         # Dependencias y scripts
├── postcss.config.js    # Configuración de PostCSS
├── tailwind.config.js   # Configuración de Tailwind CSS
└── tsconfig.json        # Configuración de TypeScript
```
